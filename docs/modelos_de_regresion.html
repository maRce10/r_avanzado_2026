Regresión lineal simple

Las regresiones lineales se basan en la ecuación lineal y = mx + b que aprendimos en el colegio. La representación formal tiene este aspecto:

\(\hat{Y} = \beta_{0} + \beta_{1} * x_{1}\)

 

  • \(\hat{Y}\): valor predicho (esperado) de la variable respuesta

  • \(\beta_{0}\): intercepto (valor esperado de la respuesta cuando \(x_{1} = 0\))

  • \(\beta_{1}\): estimado de la magnitud del efecto de \(x_{1}\) en \(\hat{Y}\) (también conocido como tamaño de efecto, coeficiente o simplemente “estimado”)

  • \(x_{1}\): variable predictora

Los valores observados de la respuesta (\(Y\)) no caen exactamente sobre la línea, por lo que el modelo completo incluye un término de error (\(\varepsilon\)) que se asume con distribución normal y promedio 0:

\(Y = \beta_{0} + \beta_{1} * x_{1} + \varepsilon, \quad \varepsilon \sim N(0, \sigma)\)

 

El objetivo más común de una regresión lineal es la estimación de los valores de \(\beta_{*}\). Esto se consigue encontrando la línea recta que mejor se ajusta y que representa la asociación entre un predictor y la respuesta:

 

Estos \(\beta_{*}\) son el tamaño de efecto estimado del predictor correspondiente (por ejemplo, \(\beta_{1}\) es el tamaño de efecto \(x_{1}\)). Su valor representa el cambio promedio en \(\hat{Y}\) (en unidades de \(Y\)) por cada unidad de cambio en el predictor correspondiente (\(x_{*}\)). Por lo tanto, la hipótesis nula es que esos \(\beta_{*}\) no son diferentes de 0 (\(\mathcal{H}_0: \beta_1 = 0\)):

\(\qquad \mathcal{H}_0: \hat{Y} = \beta_0 + 0 * x_{1}\)

lo que equivale a esto:

\(\qquad \mathcal{H}_0: \hat{Y} = \beta_0\)

1 Regresión lineal en R

Para sacar el máximo provecho de los modelos lineales necesitamos sentirnos cómodos con ellos. Empezaremos explorando la función de regresión lineal de R lm(). En R la mayoría de los modelos lineales y sus extensiones comparten formatos comunes de entrada de datos y resultados, lo que facilita su aplicación una vez que entendemos sus fundamentos.

Utilizaremos el juego de datos ‘trees’ que viene por defecto con R. ‘trees’ proporciona medidas del diámetro (etiquetado como ‘Girth’), altura y volumen de 31 cerezos talados:

Esto es lo que significan los elementos de la salida:

  • Llamada (call): la función y los parámetros que se utilizaron para crear el modelo

  • Residuos (residuals): distribución de los residuos. Los residuos son la diferencia entre lo que predijo el modelo y el valor real de y. Esta es una representación gráfica de los residuos:

 

  • Coeficientes (coefficients): contiene los tamaños de efecto (‘Estimate’), una medida de su incertidumbre (‘Std. Error’), el estadístico asociado (‘t value’) y el valor p (‘Pr(>|t|)’). Los tamaños de efecto o estimados se dan como el cambio promedio en y por cada aumento de 1 unidad en x. Para este ejemplo el estimado es de 1,0544 \(pies / pulgada\) (la altura está medida en pies y el diámetro en pulgadas). Tener en cuenta las unidades es fundamental para interpretar biológicamente el resultado: en promedio, por cada aumento de 1 pulgada en el diámetro se espera un aumento de 1,0544 pies en la altura.

  • Error estándar de los residuos (residual standard error): es la estimación de la desviación estándar del término de error (\(\sigma\)), es decir, cuánto se alejan en promedio las observaciones de la línea de regresión (en unidades de y). Se acompaña de los grados de libertad del modelo (número de observaciones menos número de parámetros estimados)

  • R-cuadrado múltiple (multiple R-squared): el coeficiente de determinación, que es la proporción de la varianza de la respuesta que es explicada por los predictores del modelo (va de 0 a 1)

  • R-cuadrado ajustado (adjusted R-squared): similar al ‘R-cuadrado múltiple’ pero penalizado por el número de parámetros

  • Estadístico F (F-statistic): estadístico para una prueba global que evalúa si al menos uno de los coeficientes de los predictores es distinto de cero

  • Valor de p (p-value): valor p asociado al estadístico F. Es la probabilidad de obtener un estadístico F igual o más extremo que el observado si la hipótesis nula (todos los coeficientes de los predictores son 0) fuera cierta

 

Utilizaremos lm() para mostrar la flexibilidad de los modelos de regresión. Los componentes de regresión se añadirán gradualmente para que podamos tomarnos el tiempo de entender cada uno de ellos así como los correspondientes cambios en la salida de la regresión.

1.1 Modelo con un predictor no asociado

Podemos crear 2 variables numéricas no relacionadas así:

Código 
# definir semilla
set.seed(123)

# numero de observaciones
n <- 50

#  variables aleatorias
y <-  rnorm(n = n, mean = 0, sd = 1)
x1 <-  rnorm(n = n, mean = 0, sd = 1)

# crear data frame
xy_datos <- data.frame(x1, y)

 

Estas dos variables pueden introducirse en un modelo de regresión para evaluar la asociación entre ellas:

Código 
# construir modelo
xy_mod <- lm(formula = y ~ x1, data = xy_datos)

# graficar
ggplot(xy_datos, aes(x = x1, y = y)) + 
  geom_smooth(method = "lm", se = FALSE) + 
  geom_point() # graficar puntos

 

Que es equivalente a esto:

Código 
# funcion para graficar tamanos de efecto con intervalos de confianza
graficar_efectos <- function(modelo) {
  ci_df <- data.frame(param = names(coef(modelo)),
                      est = coef(modelo),
                      li = confint(modelo)[, 1],
                      ls = confint(modelo)[, 2])

  ggplot(ci_df, aes(x = param, y = est)) +
    geom_hline(yintercept = 0, color = "red", lty = 2) +
    geom_pointrange(aes(ymin = li, ymax = ls)) +
    labs(x = "Parámetro", y = "Tamaño de efecto") +
    coord_flip()
}

graficar_efectos(xy_mod)

1.3 Varios predictores: regresión múltiple

La regresión lineal múltiple es una extensión del modelo de regresión lineal simple que puede tomar varios predictores:

\(\hat{Y} = \beta_{0} + \beta_{1} * x_{1} + \cdots + \beta_{n} * x_{n}\)

 

La fórmula parece compleja, pero sólo quiere decir que cualquier parámetro adicional tendrá su propia estimación (\(\beta\)). La fórmula para una regresión lineal de dos predictores se ve así:

\(\hat{Y} = \beta_{0} + \beta_{1} * x_{1} + \beta_{2} * x_{2}\)

 

… y se puede simular así (note que hacemos que ‘x2’ esté moderadamente correlacionado con ‘x1’, como suele ocurrir con los predictores en datos biológicos):

Código 
# definir semilla
set.seed(123)

# numero de observaciones
n <- 50
b0 <- -4
b1 <- 3
b2 <- -2
error <- rnorm(n = n, mean = 0, sd = 3)

# variables aleatorias
x1 <-  rnorm(n = n, mean = 0, sd = 1)
x2 <-  0.5 * x1 + rnorm(n = n, mean = 0, sd = 1) # x2 correlacionado con x1
y <- b0 + b1 * x1 + b2 * x2 + error

# correlacion entre predictores
cor(x1, x2)
[1] 0.29197

# crear un data frame
xy_datos_multp <- data.frame(x1, x2, y)

# construir el modelo
xy_mod_multp <- lm(formula = y ~ x1 + x2, data = xy_datos_multp)

Hay un punto importante que es necesario enfatizar aquí: la regresión múltiple estima el efecto de un predictor después de tener en cuenta el efecto de los demás predictores del modelo. En otras palabras, los nuevos predictores del modelo tratarán de explicar la variación de los datos que no fue explicada por los otros predictores. Así que el resultado de la regresión múltiple no es equivalente a los resultados de las regresiones lineales simples sobre los predictores por separado. Esto puede demostrarse fácilmente corriendo esas regresiones:

Código 
# coeficientes de la regresión múltiple
coef(xy_mod_multp)
(Intercept)          x1          x2 
    -3.8652      2.8677     -1.9324
Código 
# Regresión simple de y con x1
mod_x1 <- lm(y ~ x1, data = xy_datos_multp)
coef(mod_x1)
(Intercept)          x1 
    -3.4228      2.2310
Código 
# Regresión simple de y con x2
mod_x2 <- lm(y ~ x2, data = xy_datos_multp)
coef(mod_x2)
(Intercept)          x2 
    -3.3113     -1.1904

Como vemos, los tamaños de efecto para el mismo predictor difieren bastante entre la regresión múltiple y la simple. La regresión múltiple recupera valores cercanos a los simulados (3 y -2), mientras que las regresiones simples están sesgadas: como ‘x1’ y ‘x2’ están correlacionados, cada regresión simple le atribuye a su predictor parte del efecto del predictor omitido. Por ejemplo, la regresión simple de ‘x1’ estima aproximadamente \(\beta_1 + \beta_2 \times 0.5 = 3 - 1 = 2\), ya que 0.5 es la pendiente de ‘x2’ sobre ‘x1’ en la simulación.

Esto se debe a que la regresión múltiple estima el efecto de cada predictor usando solo la parte de su variación que no está correlacionada con los otros predictores (es decir, como si fueran ortogonales entre sí). Esto lo podemos comprobar sacando los residuos de cada predictor en una regresión contra todos los otros predictores en la regresión múltiple. En nuestro caso es fácil ya que solo tenemos 2 predictores:

Código 
# Regresión de x1 sobre x2 para obtener los residuos
mod_resid_x1 <- lm(x1 ~ x2, data = xy_datos_multp)

# Obtener los residuos
xy_datos_multp$residuos_x1 <- resid(mod_resid_x1)  

# Regresión de x2 sobre x1 para obtener los residuos
mod_resid_x2 <- lm(x2 ~ x1, data = xy_datos_multp)

# Obtener los residuos 
xy_datos_multp$residuos_x2 <- resid(mod_resid_x2)

Ahora si corremos las regresiones simples con estos residuos, los tamaños de efecto coinciden exactamente con los obtenidos en la regresión múltiple:

Código 
# Regresión de y sobre los residuos de x1
mod_resid_reg_x1 <- lm(y ~ residuos_x1, data = xy_datos_multp)

# Regresión de y sobre los residuos de x2
mod_resid_reg_x2 <- lm(y ~ residuos_x2, data = xy_datos_multp)

# Resúmenes finales de los modelos para comparar
coef(xy_mod_multp)[-1]
     x1      x2 
 2.8677 -1.9324
Código 
c(coef(mod_resid_reg_x1)[-1], coef(mod_resid_reg_x2)[-1])
residuos_x1 residuos_x2 
     2.8677     -1.9324

Por comodidad, hemos utilizado coef() para extraer sólo los estimados de la regresión, pero los valores son los mismos que obtenemos con summary(model).

Este punto se demuestra además por el hecho de que, si uno de los predictores no tiene ninguna influencia en la respuesta, el efecto del otro predictor será prácticamente el mismo en la regresión múltiple y en la regresión lineal simple (aunque los predictores estén correlacionados). Para simular este escenario, fijamos el efecto de ‘x2’ en 0:

    -3.9602      2.9633

1.5 Interacciones

Una interacción estadística ocurre cuando el efecto de una variable predictora sobre la respuesta depende del valor de una segunda variable predictora (es decir, el efecto está moderado o modulado por la segunda variable). Note que esto es distinto de la mediación, en la que un predictor afecta la respuesta indirectamente a través de otra variable. En la fórmula, la interacción se representa como el producto de los dos predictores:

\(\hat{Y} = \beta_{0} + \beta_{1} * x_{1} + \beta_{2} * x_{2} + \beta_{3} * x_{1} * x_{2}\)

 

Esto es más fácil de entender si se observa la interacción de una variable continua y una binaria:

2 Extender los modelos lineales a estructuras de datos más complejas

 

2.1 Modelos lineales generalizados (GLM)

Los GLM nos permiten modelar la asociación a variables respuesta que no siguen una distribución normal. Además, permiten modelar distribuciones que se asemejan más al proceso que generó los datos. El siguiente código crea un juego de datos con una respuesta que representa cuentas (por lo tanto, no normal):

Código 
# Simulación de datos
set.seed(123)  # Para reproducibilidad
n <- 100  # Número de observaciones
x1 <- rnorm(n)  # Predictor 1: variable normal
x2 <- rnorm(n)  # Predictor 2: variable normal

# Coeficientes reales para la simulación
b0 <- 0.5  # Intercepto
b1 <- 1.2  # Coeficiente para x1
b2 <- -0.8  # Coeficiente para x2

# Calcular lambda (tasa de eventos) utilizando la combinación lineal de los predictores
# En el modelo de Poisson, la tasa esperada lambda está relacionada exponencialmente con los predictores
log_lambda <- b0 + b1 * x1 + b2 * x2
lambda <- exp(log_lambda)  # Lambda debe ser positiva, por eso usamos exp()

# Generar la variable respuesta (cuentas) a partir de la distribución de Poisson
y <- rpois(n, lambda)

# Crear un data frame
xy_datos_pois <- data.frame(x1 = x1, x2 = x2, y = y)

Podemos relajar el requisito de la distribución normal con GLMs. glm() es una función básica de R que nos ayuda a hacer el truco. Para este ejemplo la distribución más apropiada es Poisson. Esto se puede establecer en el argumento family así:

Código 
glm_pois  <- glm(formula = y ~ x1 + x2, data = xy_datos_pois, family = poisson())

 

Que es equivalente a esto:

\(Y \sim Poisson(\lambda), \quad log(\lambda) = \beta_{0} + \beta_{1} * x_{1} + \beta_{2} * x_{2}\)

Es decir, la respuesta sigue una distribución de Poisson cuyo promedio (\(\lambda\)) se relaciona con los predictores a través de una función de enlace logarítmica. Por eso los estimados están en escala logarítmica.

2.2 Modelos de efectos variables (modelos mixtos)

A veces nuestros conjuntos de datos incluyen estructuras con varios niveles de organización. Por ejemplo, cuando tomamos muestras de varios individuos de diferentes poblaciones. En esos casos, la variación en el nivel estructural superior (poblaciones) podría impedir la detección de patrones en el nivel inferior (individuos).

Vamos a simular algunos datos que se asemejan a ese escenario. Tenemos un predictor continuo (x1) y una respuesta continua (y). Cada muestra procede de 1 de 8 poblaciones diferentes (poblacion). Cada población tiene su propio intercepto, que se desvía del intercepto general (\(\beta_0\)) por una cantidad aleatoria tomada de una distribución normal (esto es justamente lo que asume un modelo mixto con intercepto aleatorio). Además, las poblaciones con interceptos más altos tienden a tener valores más bajos de x1 (por ejemplo, poblaciones en sitios más fríos podrían tener individuos más pequeños pero con mayores valores de la respuesta):

Código 
# definir semilla
set.seed(10)

# numero de observaciones
n <- 300
n_pob <- 8
b0 <- 1
b1 <- 1.3

# asignar cada observacion a una poblacion

#  variables aleatorias (x1 es menor en poblaciones con intercepto alto)
x1 <-  rnorm(n = n, mean = -b_pob[poblacion] / 4, sd = 1)
y <- b0 + b_pob[poblacion] + b1 * x1 + error

# convertir a letras
poblacion <- letters[poblacion]

# crear juego de datos

Código

Que es equivalente a esto:

\(\hat{Y} = (\beta_{0} + \beta_{grupo}) + \beta_{1} * x_{1}, \quad \beta_{grupo} \sim N(0, \sigma_{grupo})\)

2.2.1 La paradoja de Simpson

La paradoja de Simpson es un fenómeno en estadística en el que una tendencia aparece en varios grupos de datos pero desaparece o se invierte cuando se combinan los grupos. Se ha utilizado para ilustrar el tipo de resultados engañosos que puede generar el ignorar la estructura en los datos y las relaciones causales entre variables.

Tomado de wikipedia

 

Los datos que simulamos en la sección anterior son un ejemplo de la paradoja de Simpson: dentro de cada población la asociación entre x1 e y es positiva, pero al ignorar las poblaciones la asociación es negativa. Esto ocurre porque el predictor (x1) está correlacionado con el grupo. La estructura de los datos debido a observaciones pertenecientes al mismo grupo puede ser tomada en cuenta usando el grupo como un factor aleatorio, tal y como se hizo en el ejemplo anterior.

 

Modelos lineales como abordaje estadístico estándar para la inferencia causal
\(g(\hat{Y}) = (\beta_{0} + \beta_{grupo}) + \beta_{1} * x_{1} + \cdots + \beta_{n} * x_{n}\)

  • Este modelo básico incluye una distribución para la respuesta (familia) y una función de enlace (\(g\)). Cuando la familia es gausiana (i.e. normal) y el enlace es la identidad (i.e. \(g(\hat{Y}) = \hat{Y}\)) equivale a un modelo lineal y cuando no, a un modelo lineal generalizado

  • Cuando el \(\beta_{grupo}\) es diferente entre grupos (i.e. cuando el intercepto difiere entre grupos) es un modelo mixto con intercepto variable (i.e. aleatorio)

 

 

Este manual solo pretende sugerir un abordaje estadístico centrado en los modelos de regresión desde el cual se pueden llevar a cabo adecuadamente la mayoría de los análisis estadísticos que usamos en investigación. El manual no tiene como objetivo explicar en detalle las particularidades de los modelos generalizados y mixtos. Note que estos modelos, principalmente los mixtos, pueden adaptarse a otras estructuras de datos más complejas no cubiertas aquí, como lo son las pendientes aleatorias, pendientes e interceptos aleatorios, estructuras de correlación (i.e. autocorrelación espacial o temporal, pedigrís o árboles filogenéticos), medidas repetidas y la pseudoreplicación, entre otras.

Las regresiones lineales se basan en la ecuación lineal *y = mx + b* que aprendimos en el colegio. La representación formal tiene este aspecto:

<center><font size = 6>$\hat{Y} = \beta_{0} + \beta_{1} * x_{1}$</font></center>

 

- $\hat{Y}$: valor predicho (esperado) de la variable respuesta

- $\beta_{0}$: intercepto (valor esperado de la respuesta cuando $x_{1} = 0$)

- $\beta_{1}$: estimado de la magnitud del efecto de $x_{1}$ en $\hat{Y}$ (también conocido como tamaño de efecto, coeficiente o simplemente "estimado")

- $x_{1}$: variable predictora

Los valores observados de la respuesta ($Y$) no caen exactamente sobre la línea, por lo que el modelo completo incluye un término de error ($\varepsilon$) que se asume con distribución normal y promedio 0:

<center><font size = 6>$Y = \beta_{0} + \beta_{1} * x_{1} + \varepsilon, \quad \varepsilon \sim N(0, \sigma)$</font></center>

 

El objetivo más común de una regresión lineal es la estimación de los valores de $\beta_{*}$. Esto se consigue encontrando la línea recta que mejor se ajusta y que representa la asociación entre un predictor y la respuesta:

```{r, out.width = "100%", echo = FALSE, fig.align= "center"}

knitr::include_graphics("./images/regression-2.jpg")

```

 

Estos $\beta_{*}$ son el tamaño de efecto estimado del predictor correspondiente (por ejemplo, $\beta_{1}$ es el tamaño de efecto $x_{1}$). Su valor representa el cambio promedio en $\hat{Y}$ (en unidades de $Y$) por cada unidad de cambio en el predictor correspondiente ($x_{*}$). Por lo tanto, la hipótesis nula es que esos $\beta_{*}$ no son diferentes de 0 ($\mathcal{H}_0: \beta_1 = 0$):

<center><font size = 6>$\qquad \mathcal{H}_0: \hat{Y} = \beta_0 + 0 * x_{1}$</font></center>

lo que equivale a esto:

<center><font size = 6>$\qquad \mathcal{H}_0: \hat{Y} = \beta_0$</font></center>

# Regresión lineal en R

Para sacar el máximo provecho de los modelos lineales necesitamos sentirnos cómodos con ellos. Empezaremos explorando la función de regresión lineal de R `lm()`. En R la mayoría de los modelos lineales y sus extensiones comparten formatos comunes de entrada de datos y resultados, lo que facilita su aplicación una vez que entendemos sus fundamentos.

Utilizaremos el juego de datos 'trees' que viene por defecto con R. 'trees' proporciona medidas del **diámetro** (etiquetado como 'Girth'), **altura** y **volumen** de 31 cerezos talados:

```{r}
head(trees)

```

 

La función básica de R para construir un modelo lineal es `lm()`. Veamos los componentes básicos de un modelo de regresión utilizando `lm()`:

```{r, out.width = "100%", echo = FALSE, fig.align= "center"}

knitr::include_graphics("./images/lm.png")

```

 

Podemos correr este modelo para ver el resultado:

```{r}
reg_mod <- lm(formula = Height ~ Girth, data = trees)

summary(reg_mod)

```

 

Esto es lo que significan los elementos de la salida:

- **Llamada** (call): la función y los parámetros que se utilizaron para crear el modelo

- **Residuos** (residuals): distribución de los residuos. Los residuos son la diferencia entre lo que predijo el modelo y el valor real de *y*. Esta es una representación gráfica de los residuos:

```{r, echo = FALSE}

# añadir valores predichos
trees$predicted <- reg_mod$fitted.values

# graficar
ggplot(trees, aes(x = Girth, y = Height)) + 
  geom_smooth(method = "lm", se = FALSE) +  
  labs(x = "Diámetro (Girth)", y = "Alto (height)") +
  geom_segment(aes(xend = Girth, yend = predicted), alpha = .2) +
  geom_point()

```

 

- **Coeficientes** (coefficients): contiene los tamaños de efecto ('Estimate'), una medida de su incertidumbre ('Std. Error'), el estadístico asociado ('t value') y el valor p ('Pr(\>\|t\|)'). Los tamaños de efecto o estimados se dan como el cambio promedio en *y* por cada aumento de 1 unidad en *x*. Para este ejemplo el estimado es de 1,0544 $pies / pulgada$ (la altura está medida en pies y el diámetro en pulgadas). Tener en cuenta las unidades es fundamental para interpretar biológicamente el resultado: en promedio, por cada aumento de 1 pulgada en el diámetro se espera un aumento de 1,0544 pies en la altura.

- **Error estándar de los residuos** (residual standard error): es la estimación de la desviación estándar del término de error ($\sigma$), es decir, cuánto se alejan en promedio las observaciones de la línea de regresión (en unidades de *y*). Se acompaña de los grados de libertad del modelo (número de observaciones menos número de parámetros estimados)

- **R-cuadrado múltiple** (multiple R-squared): el coeficiente de determinación, que es la proporción de la varianza de la respuesta que es explicada por los predictores del modelo (va de 0 a 1)

- **R-cuadrado ajustado** (adjusted R-squared): similar al 'R-cuadrado múltiple' pero penalizado por el número de parámetros

- **Estadístico F** (F-statistic): estadístico para una prueba global que evalúa si al menos uno de los coeficientes de los predictores es distinto de cero

- **Valor de p** (p-value): valor p asociado al estadístico F. Es la probabilidad de obtener un estadístico F igual o más extremo que el observado si la hipótesis nula (todos los coeficientes de los predictores son 0) fuera cierta

 

Utilizaremos `lm()` para mostrar la flexibilidad de los modelos de regresión. Los componentes de regresión se añadirán gradualmente para que podamos tomarnos el tiempo de entender cada uno de ellos así como los correspondientes cambios en la salida de la regresión.

## Varios predictores: regresión múltiple {#regresion-multiple}

La regresión lineal múltiple es una extensión del modelo de regresión lineal simple que puede tomar varios predictores:

<center><font size = 6>$\hat{Y} = \beta_{0} + \beta_{1} * x_{1} + \cdots + \beta_{n} * x_{n}$</font></center>

 

La fórmula parece compleja, pero sólo quiere decir que cualquier parámetro adicional tendrá su propia estimación ($\beta$). La fórmula para una regresión lineal de dos predictores se ve así:

<center><font size = 6>$\hat{Y} = \beta_{0} + \beta_{1} * x_{1} + \beta_{2} * x_{2}$</font></center>

 

... y se puede simular así (note que hacemos que 'x2' esté moderadamente correlacionado con 'x1', como suele ocurrir con los predictores en datos biológicos):

```{r}
# definir semilla
set.seed(123)

# numero de observaciones
n <- 50
b0 <- -4
b1 <- 3
b2 <- -2
error <- rnorm(n = n, mean = 0, sd = 3)

# variables aleatorias
x1 <-  rnorm(n = n, mean = 0, sd = 1)
x2 <-  0.5 * x1 + rnorm(n = n, mean = 0, sd = 1) # x2 correlacionado con x1
y <- b0 + b1 * x1 + b2 * x2 + error

# correlacion entre predictores
cor(x1, x2)

# crear un data frame
xy_datos_multp <- data.frame(x1, x2, y)

# construir el modelo
xy_mod_multp <- lm(formula = y ~ x1 + x2, data = xy_datos_multp)

summary(xy_mod_multp)

```

 

... graficar los tamaños de efecto:

```{r}
graficar_efectos(xy_mod_multp)

```

 

... y los gráficos diagnósticos:

```{r, out.width= "80%", fig.height=4, message=FALSE}

plot_model(xy_mod_multp, type = "diag")

```

 

Hay un punto importante que es necesario enfatizar aquí: **la regresión múltiple estima el efecto de un predictor después de tener en cuenta el efecto de los demás predictores del modelo**. En otras palabras, los nuevos predictores del modelo tratarán de explicar la variación de los datos que no fue explicada por los otros predictores. Así que **el resultado de la regresión múltiple no es equivalente a los resultados de las regresiones lineales simples** sobre los predictores por separado. Esto puede demostrarse fácilmente corriendo esas regresiones:

```{r}
# coeficientes de la regresión múltiple
coef(xy_mod_multp)

# Regresión simple de y con x1
mod_x1 <- lm(y ~ x1, data = xy_datos_multp)
coef(mod_x1)

# Regresión simple de y con x2
mod_x2 <- lm(y ~ x2, data = xy_datos_multp)
coef(mod_x2)
```

Como vemos, los tamaños de efecto para el mismo predictor difieren bastante entre la regresión múltiple y la simple. La regresión múltiple recupera valores cercanos a los simulados (`r b1` y `r b2`), mientras que las regresiones simples están sesgadas: como 'x1' y 'x2' están correlacionados, cada regresión simple le atribuye a su predictor parte del efecto del predictor omitido. Por ejemplo, la regresión simple de 'x1' estima aproximadamente $\beta_1 + \beta_2 \times 0.5 = 3 - 1 = 2$, ya que 0.5 es la pendiente de 'x2' sobre 'x1' en la simulación.

Esto se debe a que **la regresión múltiple estima el efecto de cada predictor usando solo la parte de su variación que no está correlacionada con los otros predictores** (es decir, como si fueran ortogonales entre sí). Esto lo podemos comprobar sacando los residuos de cada predictor en una regresión contra todos los otros predictores en la regresión múltiple. En nuestro caso es fácil ya que solo tenemos 2 predictores:

```{r}
# Regresión de x1 sobre x2 para obtener los residuos
mod_resid_x1 <- lm(x1 ~ x2, data = xy_datos_multp)

# Obtener los residuos
xy_datos_multp$residuos_x1 <- resid(mod_resid_x1)  

# Regresión de x2 sobre x1 para obtener los residuos
mod_resid_x2 <- lm(x2 ~ x1, data = xy_datos_multp)

# Obtener los residuos 
xy_datos_multp$residuos_x2 <- resid(mod_resid_x2)  
```

Ahora si corremos las regresiones simples con estos residuos, los tamaños de efecto coinciden exactamente con los obtenidos en la regresión múltiple:

```{r}
# Regresión de y sobre los residuos de x1
mod_resid_reg_x1 <- lm(y ~ residuos_x1, data = xy_datos_multp)

# Regresión de y sobre los residuos de x2
mod_resid_reg_x2 <- lm(y ~ residuos_x2, data = xy_datos_multp)

# Resúmenes finales de los modelos para comparar
coef(xy_mod_multp)[-1]
c(coef(mod_resid_reg_x1)[-1], coef(mod_resid_reg_x2)[-1])

```

Por comodidad, hemos utilizado `coef()` para extraer sólo los estimados de la regresión, pero los valores son los mismos que obtenemos con `summary(model)`.

Este punto se demuestra además por el hecho de que, si uno de los predictores no tiene ninguna influencia en la respuesta, el efecto del otro predictor será prácticamente el mismo en la regresión múltiple y en la regresión lineal simple (aunque los predictores estén correlacionados). Para simular este escenario, fijamos el efecto de 'x2' en 0:


En un modelo de regresión, los predictores categóricos también se representan como vectores numéricos. Más concretamente, los predictores categóricos se codifican como 0s y 1s, en los que 1 significa "pertenece a esta categoría" (en este caso 'b') y 0 "pertenece a la categoría de referencia" (en este caso 'a', que corresponde al intercepto). Mantuvimos el vector numérico original ('x1_num') al simular el juego de datos con el predictor categórico:

```{r}
head(xy_datos_cat)

```

Observe que las "b" de la columna "x1" se convierten en 1 en la columna "x1_num" y las "a" se convierten en 0. Esto se denomina variable indicadora y el proceso se conoce como 'codificación indicadora' (dummy coding).

En realidad, podemos utilizar el vector numérico en el modelo de regresión y obtener exactamente los mismos resultados:

```{r}
# resumen del modelo con la variable categórica
summary(xy_mod_cat)$coefficients

# construir modelo con la variable indicadora
xy_mod_num <- lm(formula = y ~ x1_num, data = xy_datos_cat)

# resumen del modelo con la variable indicadora
summary(xy_mod_num)$coefficients

```

 

Las cosas se complican un poco más cuando se codifica un predictor categórico con más de dos niveles. Pero la lógica es la misma: se crea una variable indicadora para cada nivel excepto el de referencia (es decir, *k - 1* variables para *k* niveles), y cada estimado representa la diferencia entre ese nivel y el nivel de referencia.
:::

## Interacciones

Una interacción estadística ocurre cuando el efecto de una variable predictora sobre la respuesta depende del valor de una segunda variable predictora (es decir, el efecto está *moderado* o *modulado* por la segunda variable). Note que esto es distinto de la *mediación*, en la que un predictor afecta la respuesta indirectamente a través de otra variable. En la fórmula, la interacción se representa como el producto de los dos predictores:

<center><font size = 6>$\hat{Y} = \beta_{0} + \beta_{1} * x_{1} + \beta_{2} * x_{2} + \beta_{3} * x_{1} * x_{2}$</font></center>

 

Esto es más fácil de entender si se observa la interacción de una variable continua y una binaria:

```{r}
y <- b0 + b1 * x1 + b2 * x2 + b3 * x1 * x2 + error

head(xy_datos_intr)

# construir modelo
# (x1 * x2 equivale a x1 + x2 + x1:x2, donde x1:x2 es el termino de interaccion)
xy_mod_intr <- lm(formula = y ~ x1 * x2, data = xy_datos_intr)

# guardar resumen para graficar lineas de mejor ajuste
```

# Extender los modelos lineales a estructuras de datos más complejas

 

## Modelos lineales generalizados (GLM)

Los GLM nos permiten modelar la asociación a variables respuesta que no siguen una distribución normal. Además, permiten modelar distribuciones que se asemejan más al proceso que generó los datos. El siguiente código crea un juego de datos con una respuesta que representa cuentas (por lo tanto, no normal):

```{r}
# Simulación de datos
set.seed(123)  # Para reproducibilidad
n <- 100  # Número de observaciones
x1 <- rnorm(n)  # Predictor 1: variable normal
x2 <- rnorm(n)  # Predictor 2: variable normal

# Coeficientes reales para la simulación
b0 <- 0.5  # Intercepto
b1 <- 1.2  # Coeficiente para x1
b2 <- -0.8  # Coeficiente para x2

# Calcular lambda (tasa de eventos) utilizando la combinación lineal de los predictores
# En el modelo de Poisson, la tasa esperada lambda está relacionada exponencialmente con los predictores
log_lambda <- b0 + b1 * x1 + b2 * x2
lambda <- exp(log_lambda)  # Lambda debe ser positiva, por eso usamos exp()

# Generar la variable respuesta (cuentas) a partir de la distribución de Poisson
y <- rpois(n, lambda)

# Crear un data frame
xy_datos_pois <- data.frame(x1 = x1, x2 = x2, y = y)

# Mostrar las primeras filas del data frame
head(xy_datos_pois)
```

También grafiquemos 'x1' *vs* 'y':

```{r}
# graficar
ggplot(xy_datos_pois, aes(x = x1, y = y)) + 
  geom_point() 

```

 

La relación no parece muy lineal ni la varianza parece ser constante a través de 'x1'.

Podemos relajar el requisito de la distribución normal con GLMs. `glm()` es una función básica de R que nos ayuda a hacer el truco. Para este ejemplo la distribución más apropiada es *Poisson*. Esto se puede establecer en el argumento `family` así:

```{r}
glm_pois  <- glm(formula = y ~ x1 + x2, data = xy_datos_pois, family = poisson())

```

 

Que es equivalente a esto:

<center><font size = 6>$Y \sim Poisson(\lambda), \quad log(\lambda) = \beta_{0} + \beta_{1} * x_{1} + \beta_{2} * x_{2}$</font></center>

Es decir, la respuesta sigue una distribución de Poisson cuyo promedio ($\lambda$) se relaciona con los predictores a través de una función de enlace logarítmica. Por eso los estimados están en escala logarítmica.

 

Como puede ver el único argumento extra comparado con `lm()` es `family`. El resto es simplemente la "fórmula" y los "datos" con los que ya estamos familiarizados. Así que, de nuevo, podemos aprovechar nuestros conocimientos sobre los modelos lineales para extenderlos a estructuras de datos más complejas.

También necesitamos ejecutar `summary()` para obtener el resultado del modelo:

```{r}
summary(glm_pois)

```


- El modelo nos dice que $\beta_1$ (el tamaño de efecto de 'x1') es `r summ_glm_pois$coefficients[2, 1]` y que `r texto_signif(summ_glm_pois$coefficients[2, 4])` (p = `r summ_glm_pois$coefficients[2, 4]`). Como el estimado está en escala logarítmica, se interpreta como que un aumento de 1 unidad de 'x1' multiplica la tasa esperada de 'y' por un factor de exp(`r summ_glm_pois$coefficients[2, 1]`) = `r exp(summ_glm_pois$coefficients[2, 1])`.

## Modelos de efectos variables (modelos mixtos)

A veces nuestros conjuntos de datos incluyen estructuras con varios niveles de organización. Por ejemplo, cuando tomamos muestras de varios individuos de diferentes poblaciones. En esos casos, la variación en el nivel estructural superior (poblaciones) podría impedir la detección de patrones en el nivel inferior (individuos).

Vamos a simular algunos datos que se asemejan a ese escenario. Tenemos un predictor continuo (x1) y una respuesta continua (y). Cada muestra procede de 1 de 8 poblaciones diferentes (poblacion). Cada población tiene su propio intercepto, que se desvía del intercepto general ($\beta_0$) por una cantidad aleatoria tomada de una distribución normal (esto es justamente lo que asume un modelo mixto con intercepto aleatorio). Además, las poblaciones con interceptos más altos tienden a tener valores más bajos de x1 (por ejemplo, poblaciones en sitios más fríos podrían tener individuos más pequeños pero con mayores valores de la respuesta):

```{r}
# definir semilla
set.seed(10)

# numero de observaciones
n <- 300
n_pob <- 8
b0 <- 1
b1 <- 1.3
sd_pob <- 4

# asignar cada observacion a una poblacion
poblacion <- sample(1:n_pob, size = n, replace = TRUE)

# desviacion aleatoria del intercepto para cada poblacion
b_pob <- rnorm(n = n_pob, mean = 0, sd = sd_pob)

error <- rnorm(n = n, mean = 0, sd = 2)

#  variables aleatorias (x1 es menor en poblaciones con intercepto alto)
x1 <-  rnorm(n = n, mean = -b_pob[poblacion] / 4, sd = 1)
y <- b0 + b_pob[poblacion] + b1 * x1 + error

# convertir a letras
poblacion <- letters[poblacion]

# crear juego de datos
xy_datos_mixto <- data.frame(x1, y, poblacion)

head(xy_datos_mixto, 10)
```

 

Podemos explorar la relación entre 'y' y 'x1' con un gráfico:

```{r}
ggplot(data = xy_datos_mixto, aes(x = x1, y = y)) + 
  geom_point()

```

 

¿Puede ver claramente el patrón de asociación entre las dos variables que hemos utilizado para simular los datos? Podemos seguir explorando los datos con un modelo de regresión lineal simple:

```{r}
lm_mixto <- lm(y ~ x1, data = xy_datos_mixto)

summary(lm_mixto)

```

 

A pesar de haber simulado un $\beta_1$ positivo (`r b1`), este modelo estima una asociación **negativa** (`r coef(lm_mixto)[2]`). Esta inferencia errónea se debe a que estamos ignorando una característica importante de nuestros datos, la agrupación de las muestras en "poblaciones".

Los modelos de efectos mixtos (también conocidos como modelos multinivel o modelos de efectos variables) pueden ayudarnos a tener en cuenta estas características adicionales, mejorando significativamente nuestro poder de inferencia. Coloreemos cada una de las poblaciones para ver cómo covarían las variables en cada subgrupo de datos:

```{r}
ggplot(data = xy_datos_mixto, aes(x = x1, y = y, color = poblacion)) + 
  geom_point()

```

 

Dentro de cada población parece haber un patrón claro de asociación positiva entre x1 e y, aunque al juntar todas las poblaciones la tendencia es negativa. El patrón se hace un poco más evidente si mostramos cada población en su propio panel:

```{r, out.width= "100%"}

ggplot(data = xy_datos_mixto, aes(x = x1, y = y, color = poblacion)) +
  geom_point() +
  facet_wrap( ~ poblacion) +
  geom_smooth(method = "lm", se = FALSE) 

```

 

Construyamos un modelo de efectos mixtos utilizando la población como intercepto variable:

```{r}
mix_eff_mod <- lmer(formula = y ~ x1 + (1 | poblacion), data = xy_datos_mixto)
```

Que es equivalente a esto:

<center><font size = 6>$\hat{Y} = (\beta_{0} + \beta_{grupo}) + \beta_{1} * x_{1}, \quad \beta_{grupo} \sim N(0, \sigma_{grupo})$</font></center>

 

Podemos ver el resultado del modelo igual que con un modelo `lm()`:

```{r}
summary(mix_eff_mod)

```

 

El modelo detectó correctamente el patrón simulado y la estimación de $\beta_1$ (`r fixef(mix_eff_mod)[2]`) es muy cercana al valor simulado (`r b1`).

<center><font size="5"><b>Interpretación del modelo</b></font></center>

- Los valores simulados de los parámetros de regresión pueden compararse con el resumen del modelo `lmer()` para tener una idea de la precisión del modelo:

  - $\beta_1$ se fijó en `r b1` y se estimó como `r round(summ_mix_eff_mod$coefficients[2, 1], 3)`.

- El modelo estimó que la desviación estándar de los interceptos entre poblaciones ($\sigma_{grupo}$) es `r as.data.frame(VarCorr(mix_eff_mod))$sdcor[1]` (simulada: `r sd_pob`). Este valor aparece en la sección 'Random effects' del resumen del modelo y también se puede obtener con `VarCorr()`:

### La paradoja de Simpson

La paradoja de Simpson es un fenómeno en estadística en el que una tendencia aparece en varios grupos de datos pero desaparece o se invierte cuando se combinan los grupos. Se ha utilizado para ilustrar el tipo de resultados engañosos que puede generar el ignorar la estructura en los datos y las relaciones causales entre variables.

```{r, out.width = "80%", echo = FALSE, fig.align= "center"}

knitr::include_graphics("./images/simpsons_paradox.gif")

```

<font size="3">Tomado de wikipedia</font>

 

Los datos que simulamos en la sección anterior son un ejemplo de la paradoja de Simpson: dentro de cada población la asociación entre x1 e y es positiva, pero al ignorar las poblaciones la asociación es negativa. Esto ocurre porque el predictor (x1) está correlacionado con el grupo. La estructura de los datos debido a observaciones pertenecientes al mismo grupo puede ser tomada en cuenta usando el grupo como un factor aleatorio, tal y como se hizo en el ejemplo anterior.

 

::: {.alert .alert-info}
<center><b><font size="5">Modelos lineales como abordaje estadístico estándar para la inferencia causal </font></b></center>

```{r, out.width = "40%", echo = FALSE, fig.align= "center"}

knitr::include_graphics("./images/swiss_knife.png")

```

<center><font size = 5>$g(\hat{Y}) = (\beta_{0} + \beta_{grupo}) + \beta_{1} * x_{1} + \cdots + \beta_{n} * x_{n}$</font></center>

- Este modelo básico incluye una distribución para la respuesta (familia) y una función de enlace ($g$). Cuando la familia es gausiana (i.e. normal) y el enlace es la identidad (i.e. $g(\hat{Y}) = \hat{Y}$) equivale a un modelo lineal y cuando no, a un modelo lineal generalizado

- Cuando el $\beta_{grupo}$ es diferente entre grupos (i.e. cuando el intercepto difiere entre grupos) es un modelo mixto con intercepto variable (i.e. aleatorio)

 
:::

 

Este manual solo pretende sugerir un abordaje estadístico centrado en los modelos de regresión desde el cual se pueden llevar a cabo adecuadamente la mayoría de los análisis estadísticos que usamos en investigación. **El manual no tiene como objetivo explicar en detalle las particularidades de los modelos generalizados y mixtos**. Note que estos modelos, principalmente los mixtos, pueden adaptarse a otras estructuras de datos más complejas no cubiertas aquí, como lo son las pendientes aleatorias, pendientes e interceptos aleatorios, estructuras de correlación (i.e. autocorrelación espacial o temporal, pedigrís o árboles filogenéticos), medidas repetidas y la pseudoreplicación, entre otras.
